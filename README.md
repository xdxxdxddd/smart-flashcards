# Smart Flashcards

An interactive web platform designed for creating and studying flashcards to improve learning efficiency and memory retention. 

## Features

- Create, edit, and manage custom thematic flashcard decks
- Add interactive double-sided cards (term and definition)
- "Study Mode" with smooth card-flipping animations
- Track learning progress and user statistics
- Fully responsive, mobile-first minimalistic interface

## Tech Stack

- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **Frontend:** HTML5, CSS3, JavaScript (Vanilla)

## Getting Started

Follow these instructions to get a copy of the project up and running on your local machine.

### Prerequisites
- Node.js (v18 or higher)
- MongoDB account (Atlas)
